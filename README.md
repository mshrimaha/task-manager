# Task Manager Application

A full-stack web application designed to help users organize and manage their daily tasks efficiently.

## 🚀 Features

- User Registration and Login
- Secure Password Hashing
- Password Validation
- Create New Tasks
- View Tasks
- Update Task Status
- Delete Tasks
- Add Task Descriptions
- Set Due Dates
- User-Specific Task Management

## 🛠️ Technologies Used

- Python
- Flask
- SQLAlchemy
- PostgreSQL
- SQLite
- HTML
- CSS

## 🔐 Security

User passwords are securely stored using password hashing. The application also includes password validation to improve account security.

## 🗄️ Database

The application uses:

- SQLite for local development
- PostgreSQL for deployment

SQLAlchemy is used for database management.

## 🌐 Deployment

The application is deployed using Render.
